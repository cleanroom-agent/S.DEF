# S.DEF Enhancement Proposals

This directory contains Enhancement Proposals for changes to the S.DEF specification.

## Process

See [Proposal Guidelines](../docs/community/proposal-guidelines.mdx) for the full process.

To submit a proposal:

1. Discuss your idea in GitHub Discussions or a Working Group first
2. Copy `TEMPLATE.md`, name it `0000-your-feature-title.md`
3. Fill out all sections
4. Submit as a pull request
5. After PR is created, rename the file using the PR number
6. Find a sponsor to champion your proposal

## Proposal Statuses

| Status       | Meaning                                   |
| ------------ | ----------------------------------------- |
| `draft`      | Has a sponsor, undergoing informal review |
| `in-review`  | Ready for formal maintainer review        |
| `accepted`   | Approved, awaiting implementation         |
| `rejected`   | Declined by maintainers                   |
| `withdrawn`  | Author withdrew                           |
| `final`      | Complete with implementation              |
| `superseded` | Replaced by a newer proposal              |
| `dormant`    | No sponsor within 6 months                |
