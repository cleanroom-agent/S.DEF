# S.DEF Specification (Draft)

This is the draft specification for the Software Definition Exchange Format.

## Document Structure

The specification is organized into the following sections:

- **Architecture** — High-level overview and design principles
- **Core Concepts** — Fundamental concepts of software definitions
- **Schema Reference** — Formal schema definitions
