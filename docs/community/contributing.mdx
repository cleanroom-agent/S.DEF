# Contributing to S.DEF

Thank you for your interest in contributing to the Software Definition Exchange Format!

## Ways to Contribute

- **Report bugs** or request features via GitHub Issues
- **Submit proposals** for spec changes via the proposal process (see [Proposal Guidelines](/community/proposal-guidelines))
- **Improve documentation** via pull requests
- **Review pull requests** from the community

## Proposal Process

For substantial specification changes, follow the Enhancement Proposal process:

1. Discuss your idea in GitHub Discussions first
2. Read the [Proposal Guidelines](/community/proposal-guidelines)
3. Copy `proposals/TEMPLATE.md` and fill it out
4. Submit as a pull request

## Development

```bash
bun install
bun run generate:schema
bun run validate
```

Before submitting a PR, run the full prep:

```bash
bun run prep
```
